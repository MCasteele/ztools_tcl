# ztools_tcl

This is a Tcl version of the "Infocom (z-machine) toolkit", found at https://inform-fiction.org/zmachine/ztools.html. It isin Tcl to facilitate rapid modification and prototyping (edit->run, instead of edit->compile->run.)

## Currently, I am working on the infodump[.tcl] tool, to dump various storyfile/storyboard infos.
